# План збірки

Після кожного кроку: `uv run bean-check main.beancount` без повідомлень, оновити `PROGRESS.md`, коміт.

## Крок 1. Основа обліку
**Зробити:** створити `main.beancount`: опції (валюта PLN), `open` для рахунків (`Assets:Банк`, `Equity:Початковий-залишок`, `Income:Зарплата`, `Income:Інше`, категорії витрат, `Expenses:Без-Категорії`), початковий залишок 4 500 зл на 31.07.2026, рядок `include "transactions.beancount"`.
**Перевірити:** `uv run bean-check main.beancount` проходить без повідомлень.

## Крок 2. Правила категорій
**Зробити:** заповнити `rules.csv` (шаблон, рахунок, фіксована): продукти, кафе, таксі, доставка їжі (Bolt Food і Wolt), косметика, спорт, підписки, зв'язок, транспорт, оренда. Конкретніші шаблони вище (`Bolt Food` перед `Bolt`). Фіксовані: оренда, ZTM, Netflix, Spotify, Claude.ai, Play.
**Перевірити:** кожен опис із виписки має правило, окрім навмисних винятків.

## Крок 3. Імпорт
**Зробити:** написати `import.py`: читає CSV з `data/`, рахує однакові рядки один раз, не сортує рядки (залишок йде в порядку банку), застосовує `rules.csv`, пише `transactions.beancount`. Фіксовані позначає тегом `#fixed`.
**Перевірити:** `uv run python import.py`, потім `bean-check`. Остаточний залишок рахунку дорівнює 17 127,34 зл (останній рядок виписки). Нічого не потрапило в `Expenses:Без-Категорії`.

## Крок 4. Збережені запити
**Зробити:** у `main.beancount` додати директиви `query`: витрати по категоріях за місяць, дохід і відкладене за місяць, фіксовані проти керованих.
**Перевірити:** `uv run bean-query` дає суми, що збігаються з ручним підрахунком за серпень.

## Крок 5. Звіт і Fava
**Зробити:** зібрати `report.html` з трьома відповідями по місяцях, жовтень з позначкою «неповний». Перевірити Fava: `uv run fava -p 5050 main.beancount`.
**Перевірити:** норма заощаджень = (дохід − витрати) / дохід; фіксовані витрати за повний місяць = 3 508,49 зл.

## Крок 6. Підтвердження з Олею
**Зробити:** показати звіт, уточнити Wolt, Play і показ жовтня.
**Перевірити:** Оля підтвердила категорії; правки внесено в `rules.csv`.
